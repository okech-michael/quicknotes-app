# QuickNotes

QuickNotes is a simple browser-based note-taking app for capturing personal, work, and study notes. Add notes with a category, search them by text, and keep them saved in your browser between visits.

## Features

- Add notes with Personal, Work, or Study categories.
- Validate note text so it is not empty and is no longer than 200 characters.
- Search note text without case sensitivity.
- Delete individual notes.
- Save notes in browser local storage so they survive page refreshes.
- See a note count and each note's category and creation date.
- Responsive layout for desktop and mobile screens.

## Run locally

Open `index.html` in a modern web browser. No build tools or dependencies are required. You can also use a local development server, such as the Live Server extension in Visual Studio Code.

## What I learned

- How to build and update page content safely with DOM methods and `textContent`.
- How to validate form input and handle add, delete, and search interactions.
- How to save and restore structured data using JSON and `localStorage`.
- How to use semantic HTML and responsive CSS to make a small app accessible and usable on mobile.
